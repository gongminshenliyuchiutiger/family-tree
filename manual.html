系統概述

本系統專為繪製家族樹、家系圖與公民科「親屬與親等」教學設計。不需安裝任何軟體，開啟瀏覽器即可於電腦、平板或手機上建立成員、設定多元家庭關係、智慧自動對齊大家族、視覺化高亮親等計算路徑，並支援 PNG／SVG 匯出與一鍵分享連結。

支援手機／平板觸控 智慧子樹自動對齊 親等計算路徑高亮 自動儲存草稿 一鍵 URL 分享 PNG／SVG 向量匯出

一、主工具列功能一覽

畫布上方為核心編輯功能列，下方為匯出、分享與管理按鈕：

新增角色

新增家庭成員至畫布，可填寫姓名、性別，並選填生卒年份與備註說明（按 Enter 可直接確認）。

編輯角色

修改已選取成員的姓名、性別、生卒年份、備註，並可上傳照片頭像（雙擊成員亦可開啟）。

刪除選擇

移除選取的單一成員，或移除已框選的多位成員及其關聯連線（快捷鍵 Delete）。

設定關係

建立 9 種關係：配偶、前配偶(再婚)、父母、子女、養父母、養子女、兄姐、弟妹、雙胞胎。

設定狀態

更改選取成員的狀態：正常、死亡（交叉線）、離婚（虛線）、失蹤（虛線）。

關係親等

計算兩位成員的親等，於畫布以彩色粗線＋步驟編號高亮計算路徑，並可連續改點其他成員查詢。

自動對齊

採用子樹重心對齊演算法：父母置於子女正上方、外家父母就近排列、同層不同家庭折線自動分層錯開。

復原 ／ 取消復原

最多保存 50 步操作紀錄（含拖曳位置），支援 Ctrl+Z 復原與 Ctrl+Y 取消復原。

顯示所有親屬關係

以選取成員為主角，分色標示所有成員的親等；長標籤自動兩行換行＋縮放字體防止重疊。

範本／專案

一鍵載入內建 3 套範本（核心家庭、三代同堂、四代聯姻大家族），或管理本機多份命名專案。

下載圖片 / SVG

支援自動緊貼裁切白邊的 PNG（白底／透明），以及無限放大不模糊的 SVG 向量圖。

分享連結

將目前家族樹壓縮編碼成網址並自動複製，對方點開連結即可直接載入檢視，免傳 JSON 檔。

匯出 ／ 匯入 JSON

將完整家族資料（含備註與頭像）存成 .json 檔案備份，日後可隨時重新匯入繼續編輯。

清除畫布

清空畫布上所有成員與關係（具防誤觸確認視窗，清除後仍可按「復原」救回）。

二、檢視、縮放與寬窄層高控制列

當家族人數多達數十人時，善用畫布上方的檢視控制列能大幅提升瀏覽與排版體驗：

控制項目 功能說明與使用時機
搜尋姓名／定位 輸入成員姓名關鍵字按 Enter 或「定位」，畫面會自動捲動至該成員中央並顯示閃爍橘色光圈。
縮放與「符合畫面」 支援 15% ~ 200% 縮放（點擊百分比重設 100%）。點「符合畫面」可一鍵將整張大家族完整縮放至視窗內檢視。

三、一鍵快速新增親屬與自動儲存

選取成員「一鍵快速新增親屬列」

點選畫布上任一位成員後，畫布上方會立即出現藍色快捷列：

＋配偶　＋父母　＋子女　＋兄姐　＋弟妹

點擊任一按鈕並輸入姓名按 Enter，系統會自動建立新成員、設定好雙向關係（新增子女時也會自動關聯其配偶），並擺放在對應的世代位置，建圖速度比手動連線快 3~5 倍！

自動儲存草稿與多專案管理

  • 自動儲存：標題旁顯示「已自動儲存 HH:MM」，每次修改皆即時寫入本機瀏覽器，不小心重整或關閉分頁，下次開啟會自動還原上次進度。
  • 多專案存檔：點擊「範本／專案」可將目前畫布命名存檔，隨時在不同班級範例或不同家族樹之間切換。

六、詳細步驟操作指南

1. 新增與編輯家庭成員

  1. 點擊「新增角色」（或先選取既有成員後，點擊快捷列的 ＋配偶 / ＋父母 / ＋子女 / ＋兄姐 / ＋弟妹）。
  2. 輸入姓名、選擇性別（男性／女性），並可選填生卒年份與備註，按 Enter 或「確認」完成。
  3. 欲修改資料或上傳照片頭像時，雙擊該成員（或點「編輯角色」），修改完畢按「儲存變更」。

2. 設定多元家庭關係

  1. 點選第一位成員（主角，紅框標示），再點擊「設定關係」。
  2. 點選第二位或多位成員（藍框標示；電腦按住 Ctrl、手機平板直接點擊即可多選）。
  3. 在面板中點擊對應關係：配偶、前配偶(再婚)、父母、子女、養父母、養子女、兄姐、弟妹、雙胞胎。
  4. 若需解除某段關係，直接雙擊該條連線即可。

3. 計算關係親等與路徑高亮

  1. 點選第一位成員，點擊「關係親等」進入查詢模式。
  2. 點選畫布上任一成員，面板立即顯示親等結果與文字計算路徑（例如：我 ↔ 丈夫 → 公公 → 哥哥 → 大姪女（共 3 親等））。
  3. 畫布會同步以彩色粗線＋步驟編號圓點高亮路徑；直接改點其他成員即可連續查詢，不需關閉面板。

4. 大家族自動對齊與微調

  1. 建立好關係後點擊「自動對齊」，系統會依世代與子樹重心重新排版。
  2. 若覺得太寬或太窄，直接拖動控制列的「寬窄（45–150）」與「層高（75–180）」滑桿即時微調。
  3. 人數較多時，點擊「符合畫面」即可一次縮放呈現完整家族樹。

七、親等與姻親計算規則說明（民法概念）

本系統依據民法親等計算原則自動推算，並特別標出公民科最容易混淆的三種姻親類型：

親屬類別 計算方式與系統標示範例
直系血親 從己身向上或向下數，一世為一親等（含養父母／養子女之擬制血親）。例：父母為 1親等直系血親、祖父母為 2親等直系血親。
旁系血親 從己身數至最近共同祖先，再向下數至該親屬，合計世數。例：親兄弟姊妹為 2親等旁系血親、伯叔姑舅姨為 3親等旁系血親、堂／表兄弟姊妹為 4親等旁系血親。
姻親(血配) 血親之配偶（從血親親等）：例：媳婦／女婿為 1親等直系姻親(血配)；嫂嫂／弟媳／妹夫為 2親等旁系姻親(血配)；伯母／舅媽為 3親等旁系姻親(血配)。
姻親(配血) 配偶之血親（從配偶與其血親之親等）：例：公婆／岳父母為 1親等直系姻親(配血)；大伯／小叔／大姑／小舅為 2親等旁系姻親(配血)。
姻親(配血配) 配偶之血親之配偶（俗稱妯娌、連襟等）：例：丈夫哥哥的妻子（大嫂）為 2親等旁系姻親(配血配)。

八、下載圖片、SVG 向量圖與一鍵分享

  • PNG 圖片（白底／透明）：點擊「下載圖片 / SVG」，預設勾選「自動緊貼裁切多餘白邊」，匯出時自動隱藏紅色／藍色選取框；若開啟「圖例」或「顯示所有親屬關係」則會完整保留在圖中。
  • SVG 向量圖：放進簡報（PowerPoint / Canva）或 Word 學習單時，無論怎麼放大列印都不會鋸齒模糊。
  • 一鍵分享連結：點擊「分享連結」即可複製包含整張家族樹資料的專屬網址（無需伺服器），直接貼到 LINE、Classroom 或社群即可讓對方點開檢視。
  • 匯出／匯入 JSON：完整保存所有成員、備註與頭像，適合長期備份與交作業。

九、注意事項與常見問題（FAQ）

系統限制與注意事項

  • 每位成員最多可設定 2 位父母；現任配偶限 1 位，若需呈現再婚請使用「前配偶(再婚)」。
  • 系統具防呆檢查：禁止將自己或直系血親設為配偶，並自動防止世代循環（例如將子孫設為自己的父母）。
  • 自動儲存草稿存放於您目前的瀏覽器本機空間（localStorage），更換裝置或清除瀏覽器資料前，建議先「匯出 JSON」或複製「分享連結」。

常見問題

Q1：手機或平板可以用來畫家族樹嗎？

可以！本系統完整支援觸控操作：單指按住角色直接拖曳移動、單指滑動空白處平移畫布、雙指捏合縮放、雙擊編輯或解除連線；在「設定關係」模式下，觸控裝置直接點擊成員即可多選，不需按 Ctrl 鍵。

Q2：大家族人物很多，畫面塞不下或太擠怎麼辦？

建議先點擊「自動對齊」，接著使用檢視列的「寬窄」滑桿（最低可調至 45）壓縮水平間距，再按「符合畫面」即可一眼全覽；想快速找特定成員可直接用「搜尋姓名」定位。

Q3：如何解除誤設的關係連線？

在畫布上直接雙擊那條配偶線、前配偶虛線或親子折線即可解除；若是剛做錯操作，也可以直接按「復原」（Ctrl+Z）。

Q4：如何把老師設計好的家族樹題目直接傳給學生？

畫好後直接點下方的「分享連結」，把複製好的網址貼到班級群組或 Google Classroom，學生點開網址就會直接載入整張家族樹，完全不用下載或匯入 JSON 檔案！
